# Web Application Fundamentals

## Q1. Role of Frontend (FE)

The frontend is the part of a web application that users see and use in their browser. It focuses on design, layout, and interaction.

- It creates the user interface using HTML, CSS, and JavaScript.
- It handles user actions like clicking buttons, filling forms, and navigation.
- It sends requests to the backend and displays the response received from the server.

---

## Q2. Role of Backend (BE)

The backend works behind the scenes and manages the core functionality of a web application.

- It processes requests coming from the frontend.
- It stores, retrieves, updates, and deletes data from the database.
- It handles security, authentication, and authorization.

---

## Q3. Business Logic

Business logic refers to the rules and conditions that control how a web application works according to business needs.

### Examples:

1. In an e-commerce website, discounts are applied only when the cart value reaches a certain amount.
2. In an online banking system, transactions are blocked if the account balance is insufficient.
3. In a food delivery app, orders can be placed only when the restaurant is open.

---

## Q4. Client–Server Model

The client–server model is a system where the client requests services and the server provides them.

- The client is usually a web browser or mobile app.
- The server processes the request and sends back a response.
- Communication happens using HTTP over the internet.

---

## Q5. Three-Tier Architecture

Three-tier architecture divides a web application into three layers.

- Presentation Layer: Handles the user interface.
- Application Layer: Contains business logic and processes requests.
- Data Layer: Manages database operations.

This architecture is used for better scalability, security, and maintainability.

---

## Q6. JavaScript as a Backend Language

JavaScript is used as a backend language because:

- It is fast and uses a non-blocking model.
- It has a large ecosystem and community support.
- Popular backend frameworks include Node.js, Express.js, and NestJS.
